# Q05 - PVC + PV existant + Deployment

**Domaine :** Storage (10 % de l'examen)
**Temps conseille :** 8 minutes

Le cluster se prepare automatiquement dans le terminal. Attends le message **LAB READY** avant de commencer.

### Comment ca marche

- Tu lis l'enonce a gauche, tu travailles dans le terminal a droite.
- A tout moment, tape `check` dans le terminal : tu vois point par point ce qui est bon ou faux.
- Le bouton **Check** en bas valide le lab quand tout est vert.
- Les indices et la solution sont repliables : ouvre-les seulement si tu bloques.
